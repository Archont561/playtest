# M1: Core Fixture Engine (`v0.1.0`)

**Status**: In Progress  
**Target Version**: `0.1.0`  
**Crates**: `playtest`, `playtest-macros`

## Objective
Deliver the Playwright-style dependency-injected fixture engine with async setup and strict LIFO teardown, surfaced through the declarative `test!` macro.

## Acceptance Criteria
- [ ] `AsyncFixture` trait with `setup()` returning fixture value and async teardown hook.
- [ ] `FixtureHandle` RAII wrapper executing teardown automatically on test exit or panic.
- [ ] `test!("title", { f1, f2 } => async { ... })` declarative macro resolving only requested fixtures.
- [ ] LIFO teardown verified: teardown hooks run in exact reverse order of fixture resolution.
- [ ] Support for panic unwinding: teardowns run even if the test body panics.
- [ ] Basic `test_skip!` macro for unconditional and runtime conditional skipping.
- [ ] 100% test coverage on lifecycle resolution and unwind guards.
