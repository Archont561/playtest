# Milestone M1: Foundation & CLI-First Distribution (`v0.1.0`)

**Status**: In Progress (reopened 2026-11-11)  
**Target SemVer**: `0.1.0`  
**Packages**: crates `playtest`, `playtest-macros`, `playtest-core`, `playtest-assets`, `playtest-cli`; `playtest-py` (PyPI); `@archont561/playtest` and its platform packages (npm); `playtest` (conda); `github.com/Archont561/playtest/go` (Go); `playtest` (R); `Playtest` (NuGet); `io.github.archont561:playtest` (Maven Central); `playtest-cpp` and `playtest-c` (Conan)

> **Why this milestone is open again.** The foundation work (`task_001` to `task_003`) is done and stays done. `v0.1.0` was never tagged or published. [ADR 0015](../adr/0015-cli-first-distribution-and-five-crate-workspace.md) moves the `playtest` CLI from M5 into the first release, so M1 now also delivers the binary, its distribution channels, and the `init` and `sync` commands (`task_050` to `task_059`).

## Objective

Establish the hermetic Pixi monorepo, reserve the package names, configure two-phase trusted publishing, and expose synchronized `VERSION = "0.1.0"` exports in all nine language targets. This part is complete.

Release `v0.1.0` as one version across the CLI and every SDK: split the Rust workspace into five crates, build the `playtest` binary with the embedded SDK files, ship it through the channels of [ADR 0016](../adr/0016-cli-binary-distribution-channels.md), and let a repository pin that version and install the Python and TypeScript SDKs from committed mirrors ([ADR 0017](../adr/0017-committed-sdk-mirrors-and-explicit-wiring.md)). This part is open.

M1 adds no test-framework features. Fixtures, macros, BDD, and property testing start in M2.

A test fails when `playtest` depends on the assets, the CLI, or `clifacet`. All five crate names are reserved on crates.io with Trusted Publishing configured (`Archont561/playtest`, `release.yml`, `crates` environment). (`task_050`)
- [x] **Embedded SDK files** (Spec 0012 §2): `playtest-assets` embeds the published files of every SDK from an explicit list, builds as a packaged crate outside the repository, and a test catches drift from the sources. (`task_051`)
- [x] **`playtest version` and `playtest init`** ([Spec 0013 §§1, 2, 6](../specs/0013-workspace-configuration-and-sdk-mirrors.md)): `init` writes only `playtest.toml` and `.playtest/`. A binary that does not match the pinned version exits with status 3. (`task_052`)
- [x] **`playtest sync` and `playtest sync --check`** (Spec 0013 §§3–5): deterministic Python and TypeScript mirrors that a fresh clone installs with uv, npm, pnpm, and Bun, without the CLI and without network access for the SDK. (`task_053`)
- [x] **Release binaries** (Spec 0012 §3): the 5-platform matrix is declared; each platform gets a `.tar.gz` or `.zip` archive with SHA-256 files on an immutable GitHub Release. (`task_054`)
- [x] **Registry channels** (Spec 0012 §§4–5):
  - PyPI platform wheels that hold the binary and the Python SDK. (`task_055`)
  - npm platform packages, the wrapper package with the TypeScript SDK, and the loader; no lifecycle script. (`task_056`)
  - A conda package (`https://prefix.dev/archont561/archont561`), and `cargo install playtest-cli`. (`task_057`)
  - Go and R download wrappers. (`task_058`)
- [x] **One version per release** (Spec 0012 §8): a release check rejects any manifest, `VERSION` constant, or embedded SDK version that differs from the release version, and package-scoped tags are retired. (`task_054`, `task_059`)
- [ ] **`v0.1.0` is tagged and published.** On every channel above, an install followed by `playtest version` prints `0.1.0`.

## Resolved Release-Chain Gaps

All six gaps identified during M1 reopening were closed across `task_050`–`task_059`:

- `build-typescript` generates real platform and wrapper `.tgz` tarballs via `automation/npm_packages.py` + `cargo-npm`, and `publish-npm` publishes platform packages before the wrapper. (`task_056`)
- `auto-release.yml` dispatches `release.yml` via `workflow_dispatch` whenever the release tag is pushed with `GITHUB_TOKEN`. (`task_059`)
- `automation/release.py` blocks accidental first-release auto-tagging on `main` pushes until an explicit milestone release tag (`milestone-v0.1.0`) or manual override cuts `v0.1.0`. (`task_059`)
- Root MIT `LICENSE` is committed and bundled into every release binary archive. (`task_054`)
- Root `pixi.toml` sets `rust >=1.88.0,<2`, matching `playtest-cli`'s MSRV. (`task_050`)
- `release.yml` Phase 1 matrices (`build-cli`, `build-python`, `build-conda`) build across all 5 supported platforms. (`task_054`–`task_057`)
