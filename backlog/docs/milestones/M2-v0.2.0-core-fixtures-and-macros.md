# Milestone M2: Core Fixture Engine & Macro Architecture (`v0.2.0`)

**Status**: Ready  
**Target SemVer**: `0.2.0`  
**Packages**: `playtest` (Rust), `playtest-macros` (Rust), `playtest-py` (Python), `@archont561/playtest` (TypeScript)

## Objective
Implement the Playwright-style dependency injection fixture engine with async setup and strict LIFO teardown, surfaced through the declarative `test!` macro family in Rust, with corresponding fixture function wrapping in Python and TypeScript.

## Deliverables & Acceptance Criteria
- [ ] `AsyncFixture` trait with `setup()` returning fixture value and async teardown hook.
- [ ] `FixtureHandle` RAII wrapper executing teardown automatically on test exit or panic.
- [ ] `test!("title", { f1, f2 } => async { ... })` declarative macro resolving only requested fixtures.
- [ ] LIFO teardown verified: teardown hooks run in exact reverse order of fixture resolution.
- [ ] Panic unwinding resilience: teardowns execute even if the test body encounters an assertion failure or panic.
- [ ] `test_skip!` and `skip_if!` macros for unconditional and runtime conditional skipping.
- [ ] Python fixture wrapper bridging pytest `yield` fixtures with identical lifecycle semantics.
- [ ] TypeScript fixture runner with destructuring injection mirroring Playwright test runner.
- [ ] 100% test coverage on lifecycle resolution and unwind guards across Rust, Python, and TypeScript.
