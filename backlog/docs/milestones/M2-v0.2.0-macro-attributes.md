## Objective
Implement procedural attribute macros in `playtest-macros` that decorate declarative `test!` invocations, enabling property testing, skipping, and parameterization.

## Acceptance Criteria
- [ ] `#[skip]` attribute macro cleanly replaces test macro invocation with an ignored test.
- [ ] `#[skip_if(condition)]` evaluates compile-time or runtime conditions.
- [ ] `#[prop(var in strategy, ...)]` attribute wraps `test!` in a `proptest!` engine loop.
- [ ] Per-sample fixture isolation: fixtures are built and torn down (LIFO) fresh for each generated sample and shrink step.
- [ ] `#[cases(...)]` macro adds table-driven test cases executing sequentially.
- [ ] Full macro error reporting with precise spans pointing to syntax mistakes.
