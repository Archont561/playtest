# Milestone M3: Fluent BDD & Property-Based Testing Integration (`v0.3.0`)

**Status**: Backlog  
**Target SemVer**: `0.3.0`  
**Packages**: `playtest` (Rust), `playtest-macros` (Rust), `playtest-py` (Python), `@archont561/playtest` (TypeScript)

## Objective
Deliver code-first BDD scenario testing with fluent method chaining (`.given().when().then()`) without external `.feature` files, and seamlessly compose BDD scenarios with property-based testing (proptest / Hypothesis / fast-check).

## Deliverables & Acceptance Criteria
- [ ] `ScenarioBuilder` state machine enforcing compile-time step progression: `Given` $\rightarrow$ `When` $\rightarrow$ `Then` $\rightarrow$ `And`.
- [ ] `test_scenario!` macro providing clean chaining syntax while injecting requested fixtures.
- [ ] Procedural macro `#[prop(...)]` decorating declarative `test!` and `test_scenario!` macros in Rust.
- [ ] Python equivalent `test.scenario.prop(...)` combining Hypothesis strategies with fluent BDD steps.
- [ ] TypeScript equivalent supporting `fast-check` generators inside scenario steps.
- [ ] Per-iteration fixture isolation: every PBT sample permutation executes in a fresh fixture lifecycle.
- [ ] Proptest failure shrinking preserved across scenario pipelines.
- [ ] Parameterized table tests via `#[cases(...)]` macro attribute.
