> **Superseded.** This file belongs to an earlier Rust-only roadmap and is kept for history. Its status line is obsolete. `v0.3.0` is now [M3: Fluent BDD & PBT Integration](./M3-v0.3.0-fluent-bdd-and-pbt.md). The current roadmap is [README.md](./README.md).

**Status**: Planned  
**Target Version**: `0.3.0`  
**Crates**: `playtest`

## Objective
Deliver a type-safe, code-first BDD scenario pipeline (`test_scenario!`) without requiring `.feature` Gherkin files, fully integrated with property testing.

## Acceptance Criteria
- [ ] `ScenarioBuilder` state machine supporting `.given(...)`, `.when(...)`, `.then(...)`, and `.and(...)`.
- [ ] Strongly typed state transitions: step return values flow directly into the next step's arguments.
- [ ] Mutable fixture access across all steps via `&mut Fix`.
- [ ] `test_scenario!` declarative macro supporting chained syntax:
  ```rust
  test_scenario! {
      "title", { db }
          .given(...)
          .when(...)
          .then(...)
  }
  ```
- [ ] Native `#[prop(...)]` compatibility: runs the entire BDD pipeline against hundreds of generated permutations with automatic shrinking.
- [ ] Zero runtime regex matching or untyped string world maps.
