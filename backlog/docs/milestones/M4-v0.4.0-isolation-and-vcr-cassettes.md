# Milestone M4: Isolation, Snapshots & VCR HTTP Cassettes (`v0.4.0`)

**Status**: Backlog  
**Target SemVer**: `0.4.0`  
**Packages**: `playtest` (Rust), `playtest-py` (Python), `@archont561/playtest` (TypeScript)

## Objective
Define portable behavior for hermetic, deterministic filesystem, snapshot, network, and clock/seed helpers; deliver the initial implementations for Rust, Python, and TypeScript. M5 requires equivalent behavior and conformance coverage for the remaining language targets before claiming full parity.

## Deliverables & Acceptance Criteria
- [ ] `tmpdir` sandbox fixture: allocates an isolated directory per test with path traversal guards and RAII cleanup.
- [ ] `snap` snapshot fixture: wraps snapshot engines with auto-redaction of non-deterministic data (UUIDs, timestamps, session tokens).
- [ ] `cassette` VCR engine: intercepts outbound HTTP requests with `Auto`, `Record`, and `Replay` modes, persisting YAML/JSON cassettes to `tests/cassettes/`.
- [ ] Strict `Replay` mode enforced in CI pipelines to prevent unexpected network calls.
- [ ] `network_guard` socket interceptor blocking unintended outbound TCP connections with explicit domain allowlisting.
- [ ] `clock` and `seed` determinism fixtures providing time-travel manipulation and reproducible PRNG crash-replay seeds.
