# M4: Standard Isolation & VCR Fixtures (`v0.4.0`)

**Status**: Planned  
**Target Version**: `0.4.0`  
**Crates**: `playtest`

## Objective
Provide a batteries-included suite of standard fixtures for filesystem, snapshot, network, and environmental isolation.

## Acceptance Criteria
- [ ] `tmpdir`: Sandboxed scratchpad directory with automatic path traversal protection and RAII cleanup.
- [ ] `snap`: Pre-configured `insta` snapshot helper with automatic regex masking for UUIDs and timestamps.
- [ ] `cassette`: VCR HTTP & callback cache with `Auto`, `Record`, `Replay`, and `Passthrough` modes, auto-saving on teardown.
- [ ] `env`: Scoped environment variable restoration ensuring no leaky state between tests.
- [ ] `clock`: Mock system time controller allowing freeze, step, and restore.
- [ ] `seed`: Deterministic PRNG seeded from test file/name, printing replay seed on assertion panic.
- [ ] `network_guard`: Outbound TCP socket interceptor that fails fast on accidental internet egress.
