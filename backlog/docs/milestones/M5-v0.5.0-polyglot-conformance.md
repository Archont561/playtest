# Milestone M5: Polyglot Extended Conformance & Cross-Language CLI (`v0.5.0`)

**Status**: Backlog  
**Target SemVer**: `0.5.0`  
**Packages**: `playtest` (Rust / CLI), `playtest-cpp` (C++), `playtest-go` (Go), `playtest-java` (Java), `playtest-r` (R)

## Objective
Extend Playtest's 1:1 fixture and BDD ergonomics to compiled and specialized target ecosystems (C++, Go, Java, R), and deliver the unified cross-language CLI engine featuring workspace auto-detection, toolchain compatibility diagnostics (`playtest doctor`), and polyglot test orchestration.

## Deliverables & Acceptance Criteria
- [ ] **Cross-Language Project Auto-Detection**:
  - Automatically identifies subprojects and testing frameworks by inspecting manifest signatures (`Cargo.toml` $\rightarrow$ Rust/nextest, `pyproject.toml` $\rightarrow$ Python/pytest, `package.json` $\rightarrow$ TS/bun, `CMakeLists.txt` $\rightarrow$ C++/gtest, `go.mod` $\rightarrow$ Go/testing, `pom.xml`/`build.gradle` $\rightarrow$ Java/JUnit 5, `DESCRIPTION` $\rightarrow$ R/testthat).
- [ ] **Toolchain Compatibility & Health Engine (`playtest doctor`)**:
  - Probes local environment for installed compilers, interpreters, and test runners.
  - Enforces minimum toolchain compatibility matrix:
    - Rust: MSRV 1.80+ (with `cargo-nextest`)
    - Python: >= 3.10 (with `pytest` and `pytest-cov`)
    - TypeScript: Node >= 18 or Bun >= 1.0 (with `bun test` / Playwright)
    - C++: GCC >= 11 or Clang >= 14 supporting C++20
    - Go: >= 1.21 (with `go test` and `rapid`)
    - Java: OpenJDK >= 11 (with JUnit 5 and `jqwik`)
    - R: >= 4.1 (with `testthat` and `hedgehog`)
  - Emits clear diagnostic warnings and remediation instructions on missing or outdated toolchains.
- [ ] **Unified Polyglot Test Orchestration (`playtest test`)**:
  - Executes tests across all detected language targets or selectively via `--lang <target>` / `--filter <pattern>`.
  - Aggregates multi-language test results into unified terminal output, JSON reports, and JUnit XML.
- [ ] **Target Language Conformance Implementations**:
  - C++: GoogleTest fixture facade with RAII cleanup and RapidCheck PBT integration.
  - Go: Go testing facade utilizing `t.Cleanup` for reverse LIFO teardown and `rapid` for property testing.
  - Java: JUnit 5 extension engine with `jqwik` property testing and fluent BDD builder.
  - R: `testthat` fixture helpers with `on.exit(..., add = TRUE)` and `hedgehog` property integration.
- [ ] **Cross-Language Conformance Test Suite**:
  - Automated test harness running golden vectors identically across all 7 runtimes to verify 1:1 fixture lifecycle and teardown parity.
