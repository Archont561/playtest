# Milestone M7: Ecosystem Integration Fixtures (`v1.1.0`)

**Status**: Backlog  
**Target SemVer**: `1.1.0`  
**Targets**: Rust, Python, and TypeScript packages, with tier/CLI support from the shared `playtest` CLI.

## Objective

Add the post-core, opt-in integration layer defined in [Spec 0009](../specs/0009-ecosystem-integration-fixtures.md): application fixtures for Rust (clap CLIs, ratatui TUIs, Tauri desktop/mobile apps), desktop GUI application fixtures (Qt and tkinter) for Python, and browser integration for client-side JavaScript in TypeScript. These capabilities ship only after each receiving package's core common capabilities (Spec 0005 parity; the coordinated `v1.0.0` release for Rust) are complete, as SemVer-minor additions that never disturb core parity claims. [ADR 0013](../adr/0013-scoped-browser-drop-and-ecosystem-integration-fixtures.md) records the scoping relative to ADR 0004.

## Deliverables & Acceptance Criteria

- [ ] **Rust `cli_app` fixture** (clap):
  - In-process runs against the app's `CommandFactory` with per-test argv, captured output, and structured exit status; handlers receive fixtures via standard DI.
  - Snapshot-golden help/usage/error text; optional spawned-binary mode with failure-safe child reaping.
- [ ] **Rust `tui_app` fixture** (ratatui):
  - Headless `TestBackend` default with direct or snap-asserted buffers; injected key/mouse/paste events; clock-driven frame stepping.
  - Real-terminal mode fail-loud on hosts without a usable tty.
- [ ] **Rust `tauri_app` fixture** (Tauri):
  - In-process host (commands/state/plugins) as the always-runnable default; opt-in real-host mode for desktop webviews and mobile emulator sessions following the qualification-harness pattern.
  - Doctor probes for webview runtimes and mobile emulators; nothing heavyweight in core installs.
- [ ] **Python `qt_app` fixture**:
  - Process-singleton `QApplication` host (PyQt6/PySide6, documented binding selection), offscreen by default.
  - Per-test top-level windows closed in strict failure-safe LIFO order; event pumping driven by the injected clock.
  - Explicitly requested run without a usable Qt platform fails with remediation instead of skipping green.
- [ ] **Python `tk_app` fixture**:
  - Fresh withdrawn `Tk` root per test, destroyed failure-safe in LIFO order; `after`-based pumping on the injected clock.
  - Missing Tk support under explicit request fails with remediation.
- [ ] **TypeScript `browser` fixture**:
  - Playwright as optional peer dependency; core installs download no browser binaries.
  - Fresh context per test with failure-safe LIFO closure; deterministic waiting for client-side JavaScript.
  - Missing browser under explicit selection fails with remediation; network routing mapped to `cassette`/`network_guard` semantics.
- [ ] **Integration tiers and reporting**:
  - `gui`, `browser`, and `mobile` tiers declared, mapped per target, and visible in `playtest list`.
  - Doctor probes for Qt platform, tkinter presence, browser binaries, Tauri webview runtimes, and mobile emulators.
  - Integration conformance results reported separately from Spec 0005 core parity.
